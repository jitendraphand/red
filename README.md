# Homi Bhabha Class 6 – Electricity & Magnetism Quiz

Interactive practice quiz with **50 questions** on Electricity & Magnetism for Class 6 Dr. Homi Bhabha Balvaidnyanik Competition.

## Features
- 50 exam-standard multiple-choice questions
- **60-second timer** for each question
- Auto-advance on timeout
- Instant results with score and detailed review (correct answers + explanations) after submission
- Clean, mobile-friendly interface

## Live Site (GitHub Pages)

## Topics Covered
- Electric current, circuits, conductors & insulators
- Units (ampere, volt, ohm)
- Energy conversions (battery, bulb, electromagnet)
- Magnets, poles, magnetic materials, magnetic field
- Electromagnets and their uses
- Practical applications matching Homi Bhabha exam style

Questions are designed to match the quality and pattern of Class 6 Homi Bhabha / Maharashtra State Board Science syllabus.
